# GSTPilot Product Terminology

Version: 1.0.0

Status: Active

Last Updated: July 2026

---

# Purpose

This document defines every important business term used throughout GSTPilot.

Every AI Coding Assistant, Developer, Designer and Product Manager MUST use the terminology defined here.

Never invent new names for existing concepts.

If a new business concept is introduced, this document MUST be updated first.

---

# Business Hierarchy

Workspace
└── User
└── Client
└── GSTIN
└── Party
└── Invoice
└── Return
└── Report

This hierarchy must never be violated.

---

# Workspace

Definition

A Workspace is the highest level container inside GSTPilot.

Every record belongs to one Workspace.

Examples

Individual User

Workspace
└── Saad Business

CA Firm

Workspace
└── ABC Associates

Future Enterprise

Workspace
└── XYZ Pvt Ltd

Database

workspace

Never call it:

- Company
- Tenant
- Business
- Organization

Always use:

Workspace

---

# User

Definition

A person who logs into GSTPilot.

Examples

- Owner
- Accountant
- CA
- Staff

Database

user

A User belongs to exactly one Workspace in Version 1.

Future versions may support multiple workspaces.

---

# Client

Definition

A business managed inside GSTPilot.

Examples

ABC Traders

XYZ Pvt Ltd

Rahul Enterprises

A Workspace can have multiple Clients.

Database

client

Never confuse Client with User.

A User logs in.

A Client is a business.

---

# GSTIN

Definition

Goods and Services Tax Identification Number.

Each Client may own one or more GSTINs.

Database

gstin

Each GSTIN belongs to one Client.

---

# Party

Definition

A customer or supplier involved in transactions.

Examples

Customer

Vendor

Supplier

Dealer

Distributor

Database

party

Never create separate Customer and Vendor tables.

A Party has a Type.

Example

Customer

Supplier

Both

---

# Invoice

Definition

A GST transaction.

Invoices reference one Party.

Database

invoice

Every Invoice belongs to:

Workspace

↓

Client

↓

GSTIN

↓

Party

# Validation

Definition

A process that checks uploaded data.

Validation NEVER modifies data.

Validation only reports issues.

---

# Compliance Engine

Definition

Business rules responsible for converting validated data into GST-compliant structures.

Responsibilities

Tax Calculations

GST Rules

Output Preparation

Future

Additional GST Forms

Never call this:

GST Processor

Tax Engine

Business Logic

Always use

Compliance Engine
